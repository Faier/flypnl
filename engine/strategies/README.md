## 试错纪律（写给未来的自己）

1. **不砍观察期**：看到第一眼机会就上真钱 = 把最贵的学费交给最便宜的数据。
2. **尘单幻影**：Polymarket 长尾市场的最优卖价经常只有几份深度——没有深度
   记录的"套利"一律当不存在。
3. **持续性 > 名义值**：1h 间隔资金费率 ±100% 年化大多是行情噪声，
   观测均值（我们自己的时间序列）才是真相。
4. **每笔真钱实验必须有当日熔断**：亏损上限写进下单代码，不靠人手。
5. 淘汰是常态：7 个实验里活下来 2 个就是好年份。

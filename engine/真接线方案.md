# 真接线方案：把 MaleCNS v1.0 真实连接组接进 FlyGate

> 目标：用 Janelia MaleCNS v1.0 的**真实接线**（166,700 神经元 / 25,582,938 边 /
> 124,177,617 突触接触）替换 `brain/flybrain.py` 里手搓的合成接线，
> 其他部分（图表渲染、broker、风控、协议测量）全部不动。
>
> 诚实声明同 StonkFly：真实接线 ≠ 真果蝇能盈利交易。接线只是解剖学约束。

注意：flygate 的观测周期是 60s 墙钟，真接线版建议每观测推进 **500ms 神经时间**

numpy 稀疏可行但紧；先跑 MB+DN 子图（KC/MBON/DAN/DN ≈ 数千细胞），
全图版再考虑事件驱动或 C++ 内核（可参考 StonkFly kernel.cpp）。

## 3. 实施阶段（每阶段都有 protocol 硬门）

- **A. 数据（已完成 ✔）**：下载+载入器+校验脚本，全部数字与官方/StonkFly 一致。
- **B. 通道校验（已完成 ✔，2026-09-28，`runs/channel_check.py`）**：
  - **通路存在**：R1-R6 →KC 最少 **3 跳**、R7/R8 →KC 最少 **2 跳**（全量边含弱边，
    之后应做 w≥2 的强边复查）。K 线图的光在真实接线上确实能进蘑菇体。
  - **稀疏展开是真的**：进入 KC 的边 21,580 条 / 370,732 接触；每个 KC 都有输入
    （中位 190 条入边）。注意统计口径宽（含 LC/T4/T5 视觉型），经典嗅觉
    微小球是 ~7 uPN/KC，C 阶段做 MB 亚区时应按 calyx 精确筛选。
  - **APL 是 KC 的第二大输入源**（196,200 接触，仅次于 KC↔KC 复发边）——
    真实接线里反复抑制就是这么突出，`mbon_inhibition=true` 这个设置有解剖学依据了。
  - **多巴胺落点是真的**：PAM11→KC 6,702 边、PPL101→KC 4,936 边（另有 →MBON 119/52）。
  - **结论：通道成立，C 阶段可以开工。**
- **C. 静态接线跑通（已完成 ✔，2026-09-28）**：
  - 实现：`flygate/brain/realwired.py`（构建真实子图并缓存）+ `FlyBrain.real_wired`
    开关（`flybrain.py`）：KC 群体换成 **3,679 个真实基底 KC**（MBON07/11 的真实
    投射群），`kc_mask` 换成 **1,627 个外源细胞 → KC 的真实接触矩阵**（49,737 边），
    `w_a/w_v` 换成 **真实 KC→MBON07/11 边**（3,651+4,184 条，权重=接触数/组内 max）。
    新臂 `real_wired`（冻结）、`frozen_dn`/`real_wired_dn`（开 MBON→DN 通道）、
    `real_wired_learn`（D 阶段）。速度与合成大脑相同（11ms/观测）。
  - 必要修复：MBON 保证金否决在 `div==0`（尚无学习不对称）时跳过——真实接线的
    ±0.01 结构性 marg 抖动曾被当成"学到的回避"，把 real_wired 锁成 0 笔
    （该修复对全部合成臂验证为逐位无操作）。
  - **结果（3 天真实 1m × 3 种子 × 4 币）：real_wired ≡ frozen ≡ frozen_dn ≡
    real_wired_dn，逐位一致。** 三层机制都已查明：
    1) 通道关闭时 MB 只影响 g 门（真实 ~0.49 / 合成 0.50，从不低于 0.45）；
    2) 通道打开（mbon_to_dn）后 DN 放电率确实移动（dn_up 23.4 vs 20.1 Hz），
       但 w_a/w_v 驱动是**共模**的，`diff = r_up − r_dn` 不变，而决策只读差值；
    3) 结论：**冻结突触下接线必然惰性——接线只有通过学习的不对称才可能进决策。**
    这与 flybrain.py 文档钉住的结构性测试（决策=倾斜阈值）完全一致。
- **D. 学习上线（已完成 ✔，2026-09-28）**：
  - 实现：真实边的可塑性语义——逐边基线（接触数/组 max）、界限 **0.1×–2× 自身
    基线**（Huang/Luo 2024 / StonkFly 同族）、非边恒 0、遗忘衰减向各自基线
    （不再向合成的 1.0 漂移）。臂：`real_wired_learn`（真实接线+学习开）。
  - **结果：real_wired_learn ≡ learn 逐位一致。** 原因实测：3 天里多巴胺只触发
    **3 次**（全 punish，手续费门槛），每次权重改动 ~1e-4，不足以翻转任何决策。
    **通道活着但饥饿——约束在多巴胺调度，不在接线。**
- **P0. 教学信号换成整笔盈亏（已完成 ✔，2026-09-28）**：
  - 实现：`FlyBrain.teach_trip`——一笔交易平仓时，把**这笔交易存续期间屏幕上的

  - **P3. 极限研究工具箱（已完成 ✔，2026-09-30，phase01-metrics-safety）**：
    动机：112 天判决之后，"果蝇网络的极限到底在哪"需要一个直接的测量，

    1. **方向垄断重测**（`scripts/tilt_monopoly.py`，写入 `runs/tilt_monopoly.md`）：

       BTC/ETH/SOL × 988 个冻结 15m 观察：R²(diff ~ tilt) = 0.986–0.988，

       **判决：垄断仍在**。蘑菇体仍然只调制"要不要动"，调不了"往哪边"。

       对照（0.986 vs 0.960）——MBON 驱动贡献了一个与 tilt 相关的分量，
       把速率压缩的非线性"填直"了。
    2. **可达策略空间扫描**（`scripts/reach_scan.py`，写入 `runs/reach_scan.md`）：
       在 0.1x–2x 生物界限内（以及完全无界限的对照搜索）找能把"大涨前
       模式"与"大跌前模式"分开的边权 d=w_a−w_v，时间前后 70/30 留出评估，
       随机标签对照。结果：留出段分离率 box 0.067–0.258、free 0.169–0.281，
       **全部不超过随机对照（0.124–0.292）**。上限不在权重空间也不在界限，
       在视觉编码（tilt/光流）本身——KC 线性读出不携带该信号。
       SOL 的 box=0.067 远低于 0.5：跨段**反推**（regime 翻转），正是
       112 天判决"学习一致性破裂"在模式层面的回声；滚动窗口重扫是下一个
       探针。方法论注意：7835 个自由参数对 ~300 个模式，样本内分离会
       虚高（首次跑法在样本内 0.72 vs 随机 0.67 的"信号"全是过拟合），
       一切结论以留出段为准。
    3. **反事实对账**（engine → `runs/counterfactual.jsonl`，报表
       `scripts/cf_report.py`）：学习蝇的 DN 触发但被 gate/r2/marg/ring
       否决时，记录是哪个门拦的；同一根 K 线上冻结孪生的决策自动补全，
       报表把每次否决用孪生的已实现盈亏定价——"每道门值多少钱"第一次
       可以按机制归因，而不是只看 A/B 总差距。
    4. **边界饱和度**：`FlyBrain.edge_saturation()` 统计活跃边被
       |u|≥0.8 钉住的比例，进 dashboard 学习面板 + w_curve 第 6 列，
       ≥30% 时日志告警——界限（而非数据）开始决定权重的信号。
       实测 09-30：SOL 学习臂 2 天即有 14% 活跃边钉界（效能 0.108x–1.999x）。
    5. **多巴胺幅度编码**（`brain.dan_magnitude_coding`，默认关）：
       脉冲率 = dan_pulse_hz × min(|Δequity|/阈值, dan_mag_cap=4)。二值
       标签把冻结蝇唯一赚钱的非对称（少数大趋势骑乘 vs 大量手续费级小亏）
       扔掉了——+14U 和 +0.05U 过去教同样的 80Hz。诚实声明：幅度→率是
       工程约定（同脉冲本身），flag 保留对照能力。
    6. **非对称惩罚死区**（`brain.punish_deadband_mult`，默认 1.0=对称）：
       惩罚要过 mult×阈值。实测动机：09-29~09-30 trip 教学 14 惩 1 奖，
       w_a 均值被压 −25%（0.2003→0.1502），学习蝇 2 天 3 个来回 vs 孪生
       42 个——惩罚主导的教学存在"多罚→门关→断粮"的负反馈，均衡点是
       永不交易。config.json 已设 2.0（重启引擎生效），惩罚只教"明显错"。
    结论：极限的测量结果指向同一个地方——**天花板在视觉编码（上游），
    不在学习规则（下游）**。学习机制层面的修复（5、6）让"学到的东西"
    更合理，但要突破上限需要给视网膜/薄板通路新的信息源（更长的窗口、
    多时间尺度、或跨币共享输入），这是 P4 的候选题目。

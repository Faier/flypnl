# FlyGate 🧠 — 果蝇大脑 × Gate.io 自动交易系统

灵感来自 [StonkFly](https://github.com/nftechie/stonkfly)（果蝇连接组炒 BTC）与
Google 深度参与的果蝇连接组计划（[FlyWire](https://flywire.ai/) / MaleCNS）。
本系统把果蝇视觉→蘑菇体→下行神经元通路做成一个**细胞类型级缩减版脉冲神经网络**，
看着 K 线图做交易决策，盈亏通过多巴胺机制在线改变突触。

> ⚠️ 诚实声明（同 StonkFly）：**没有任何证据表明果蝇大脑能学会盈利交易**。
> 本项目回测显示：趋势跟随读出 + 仓位/风控上限能显著降低暴跌损失，
> 但 dopamine 学习相对冻结突触的增益**未获证明**。请把它当研究玩具，别当印钞机。

## 大脑结构（每个币一只独立的"蝇"）

```
Gate 1m K线 → 图表渲染(48×27像素, 垂直6×超采样+光学模糊)
  → 视网膜 R1-R6 亮度 / R8 颜色（大脑只看像素，看不到价格/余额）
  → 板层 LMC 中心-周围对比
  → 小叶倾斜检测（折线斜率+R²相干性；自动缩放图表会抵消帧间运动，
     趋势信息在线条"方位"里——方位选择性是真实小叶回路）
  → 蘑菇体: 800 Kenyon细胞稀疏编码 → MBON接近/回避，盈亏→多巴胺(PAM/PPL式)
     在线改变 KC→MBON 突触（跨观测资格迹关联"当时的图"与"之后的盈亏"）
  → 下行神经元 DN↑ / DN↓ / 承诺DN（LIF, 0.1ms步长, 400ms压缩神经时间/观测）
  → 决策: rate(DN↑)-rate(DN↓) ≥ +2Hz 且承诺神经元放电 且 门控g>0.45 且 R²≥0.85 → 买入
```

## 快速开始

```bash
# 1) 拉历史（Gate 限制：每周期最多约1万根，1m≈7天）
python3 -m flygate fetch --days 7

# 2) 回测（四组对照是 StonkFly 文档要求的验证协议）
python3 -m flygate backtest --all --all-modes

# 2b) 多臂 × 多种子 × 自举置信区间（可归因的那一版；见"测量协议"一节）
python3 -m flygate --config config.backtest.json protocol --all --days 3 --seeds 3

# 3) 纸面交易（真实行情+假钱+仪表盘，无需API key）
python3 -m flygate paper
# 打开 http://127.0.0.1:8787

# 3b) paper 自玩：教学开启（整笔盈亏→多巴胺）+ 冻结影子对照
#     学习蝇 vs 影子蝇的配对权益曲线 = "教了有没有用"的实况答案
python3 -m flygate paper --shadow

# 4) 实盘（需要 .env 里的 API key，先跑预检）
cp .env.example .env   # 填入 FLYGATE_KEY / FLYGATE_SECRET
python3 -m flygate live --preflight-only
python3 -m flygate live
```

## 多币种

`config.json`（可选，复制默认值修改）：
```json
{"pairs": ["BTC_USDT", "ETH_USDT", "SOL_USDT", "PONS_USDT"]}
```
每对独立大脑、独立预算（默认100 USDT/对）、独立状态文件（可断点恢复）。

不改配置文件、临时换币，用命令行参数（现货 + 合约都行）：
```bash
python3 -m flygate paper --pairs BTC_USDT,DOGE_USDT          # 本次只跑这两对现货
python3 -m flygate live  --contract ZEC_USDT                 # 本次合约跑 ZEC（自动启用合约腿）
python3 -m flygate paper --no-futures                        # 本次关掉合约腿
```
币种优先级：命令行 > `config.json` 的 `pairs`/`futures.contract`。新对的预算
取 `budgets`，没有则用 `quote_budget` 默认值。

## 订单流水（`runs/orders.jsonl`，重启不丢）

每笔**确认成交**追加一行（现货+合约、paper+live 全在里面；回测不写）。
之前 paper 重启会丢成交记录、live 依赖交易所查询上限——现在这是唯一权威流水：
```bash
python3 -m flygate orders                       # 最近 50 笔
python3 -m flygate orders --pair FUT:ZEC_USDT --last 100
python3 -m flygate orders --mode fut-live       # 只看真金白银的合约单
```
仪表盘新增「📋 订单流水（全量逐笔）」表，接口 `GET /api/orders?pair=&mode=&limit=`。
每行字段：`seq/time/pair/side/price/base/quote/fee/reason/mode`，`seq` 跨重启连续。
每日战报（`/api/daily`）的币种与预算现在跟随 `config.json`，不再是硬编码清单。

## 新币雷达（`python -m flygate radar`，仪表盘 `/radar`）

**只做新币**：每 15 秒扫描各链**可验证上线时间且 ≤6 小时**的新代币（成熟币和无法验证币龄的直接跳过），
逐个跑 GoPlus 合约审计（貔貅/增发/冻结/税率/持仓集中度），叠加纸级流动性、超低市值、破位跳水等
风险门，输出启发式风险徽章；支持自选持仓盯盘（实时 PnL + 5 分钟异动预警）。

**诚实边界（同上文的诚实声明文化）**：
- 本雷达**不追踪任何钱包的链上成交**——未接入钱包级数据源，因此不产生
  "聪明钱买入"事件，也没有跟单信号。任何此类数字都只能是编造的。
- 安全审计 **fail-closed**：GoPlus 不可用时标记 `UNKNOWN` 并按不可信处理，
  绝不默认"安全"。代币拿不到 `pairCreatedAt` 时币龄如实显示"未知"（且不进新币榜）。
- **推荐回测追踪**（`runs/radar_picks.json`，仪表盘"📈 回测追踪"页）：
  每个首次推出的新币按当时价格纸面记录，1/6/24 小时后自动回填真实涨跌，
  按徽章分组统计胜率/均值/中位数。这是徽章有效性的实测闭环——
  **在样本积累到统计显著之前，任何徽章都不应被当作买入依据**。

## 自玩教学（P2：教果蝇自己玩现货）

回测里的教学（P0/P1）从 2026-09-29 起接进了引擎：

- **一笔交易 = 一次多巴胺**：任何全平（脑卖出/反射止损/熔断强平）时，
  把持仓期间屏幕上的图式与这笔的**已实现盈亏（净费用）**配对触发多巴胺。
  盯市噪声不教（1×手续费死区）；盈亏不过自身费用门槛就教回避。
- **冻结影子对照（`--shadow`）**：同一行情流上并跑一只只关学习的孪生蝇，
  自己的 paper 账户、同一套风控。**学习是否有用的唯一实况标准：学习蝇的
  配对权益曲线优于冻结孪生，且差距够稳（≥4 周）**——在此之前别上实盘。
- paper 默认 brain 配置 = P1 组合（真接线蘑菇体 + Huang/Luo 2024 规则 +
  整笔教学）。诚实声明同前：能教的目前只有"回避"，量级 ±0.1~0.7pp/6天，
  离 edge 很远。

## 风控（比 StonkFly 更严）

- 单笔 10 USDT / 持仓上限 60 USDT / 每对每日单数上限（config 可配，0=不限）/ 冷却 300s
- 当日亏损 20 USDT 或峰值回撤 20% → **强制清仓+熔断**（StonkFly 只停单不清仓）
- 仪表盘一键熔断按钮；`runs/KILL` 文件同样触发
- 实盘密钥仅需现货交易权限，**绝不给提现权限**，建议绑定 IP 白名单 + 独立子账户

### 这张表怎么读（2026-09-28 复核）

三条会让上表结论失效的口径问题，已在新代码里修掉：

1. **`冻结突触` 旧口径多拆了一个机制**：`frozen=True` 除了关掉多巴胺，还顺手把
   MBON 门和 r² 门一起旁路（`decision_ok = True`）。两臂差两个机制，
   所以"frozen ≈ fly"不能推出"学习没有增量"。现在 `frozen` 只关可塑性，
   旧口径保留为 `frozen_legacy` 供复现。
2. **`买入持有` 是满仓免手续费指标，策略是 10/60 USDT 上限**——两者暴露差一个数量级，
   "跑赢持有"多半是仓位算术。回测现在同时给 `bh_matched_return_pct`
   （同样暴露路径 + 扣掉手续费）和 `time_in_market_pct`。
3. **旧表是单次运行**：没有种子、没有置信区间、没有置换对照。
   `python -m flygate protocol` 输出多种子均值 + 自举区间 + 每个臂对 `normal`
   的配对差值；区间跨 0 就是"买不到可测差异"。

另外：旧的 `buyhold` 臂其实是"下一根开盘买一次然后持有"（暴露 ≈ order_notional/预算 ≈ 10%），
而 `buyhold_return_pct` 是满仓——同一个词指两件事，这一栏已经在输出里分开标注。

### 复核结果（2026-09-28, Gate 真实 1m, 4 币各 1429–1430 根, 3 种子, 0.2% 费率+5bp 滑点）

命令：`python -m flygate --config config.backtest.json protocol --all --days 1 --seeds 3`
（原始 JSON：`runs/reports/protocol_report.json`）

| 币 | normal | frozen | frozen_legacy | random | buyhold | rewired |
|---|---|---|---|---|---|---|
| BTC | −0.478% | −0.478% | −0.584% | −0.403% | **−0.275%** | 0.000%（0 笔） |
| ETH | −0.497% | −0.497% | −0.604% | −0.401% | **−0.242%** | 0.000%（0 笔） |
| SOL | −0.484% | −0.484% | −0.751% | −0.415% | −0.504% | 0.000%（0 笔） |
| PONS | **−0.257%** | −0.257% | −0.728% | −0.392% | −1.387% | 0.000%（0 笔） |

（暴露匹配基准：BTC −0.377% / ETH −0.427% / SOL −0.415% / PONS −0.239%）

四条读得出来的结论：

1. **`normal` 与 `frozen` 一模一样（4 币全部完全相同）**，因为乘上手续费的多巴胺门槛让
   一天内**一次多巴胺事件都没有**（同一段数据单跑输出的 DA 计数是 0）。也就是说：
   在线学习不是"增量不显著"，而是**根本没被触发**。旧表里"frozen ≈ fly"的结论
   因此不再成立——它俩现在恒等。
2. **`frozen_legacy` 与 `frozen` 的差（0.11–0.47pp）全部来自门控旁路**，与学习无关。
   这正好量化了旧对照的混淆：旧表里那一列差异是门，不是多巴胺。
3. **种子对大脑臂完全无效（区间宽度 0）**：随机 PN→KC 接线改变不了任何结果——
   决策方向只由 tilt 标量决定（见 `tests/test_protocol.py` 的结构性测试）。
   只有 `random` 臂的区间是宽的（它由种子驱动）。
4. **每个臂都跑不赢自己的暴露匹配基准**（差值 ≈ 手续费拖累 + 信号无效）；
   `rewired` 臂 0 笔成交——把图表的几何结构打乱后，策略**根本不开仓**。

### 多巴胺门槛实测（1 天真实 1m，4 币）

跑 `dopamine_fee_multiple` ∈ {0, 0.25, 1, 3}（门槛 = 该倍数 × 往返手续费 0.04 USDT）：

| 倍数 | 每天多巴胺事件数（reward/punish） | 含义 |
|---|---|---|
| 0.0（旧默认 0.01 绝对额） | 44–98 次 | 1 分钱级别的盯市噪声在"教"大脑 |
| 0.25 | 与 0.0 完全相同 | 小额订单下费用项还没起作用 |
| **1.0（新默认）** | **0–5 次** | 唯一有明确含义的门槛：收益至少要覆盖这笔交易自己的成本 |
| 3.0（我上一版设的） | **0 次** | 通道直接死掉 |

同一批数据上，`normal` 与 `frozen` 的收益在倍数 ≤0.25 时**更差**（PONS：学习开启 −0.530% vs
关闭 −0.257%）。也就是说这条学习通道：**开着有害、关掉没用** —— 结论是**不要在这条通道上调参，
要么换目标函数（按整笔交易的实际盈亏、动作门控、波动率归一），要么承认它是惰性的。**

### 接线臂 `mbon_dn` 与学习臂 `learn` 的实测（同源数据 3 天, 4222 根, 2 种子, jobs=8）

命令：`... protocol --all --days 3 --seeds 2 --arms normal,frozen,mbon_dn,learn --jobs 8`
（并行 271 秒完成；同一批串行约 30 分钟）

| 币 | normal | frozen | mbon_dn | learn |
|---|---|---|---|---|
| BTC | −0.734% | −0.785% | −0.704% | −0.704% |
| ETH | −0.806% | −0.806% | −0.702% | −0.702% |
| SOL | **−0.592%** | −0.935% | −0.754% | −0.829% |
| PONS | −0.651% | −0.625% | −0.587% | −0.587% |

怎么读（**结论比上一版更保守，这是重点**）：

- **`learn` 与 `mbon_dn` 在 3/4 币上完全相同**（SOL 上 `learn` 更差）。也就是说
  "把资格迹归一化、单步有效性提高 3.1 倍"**没有改变结果**——因为多巴胺一天只触发
  0–5 次，步长大 3 倍依然接近于零，遗忘仍以 30:1 压着。
- **上一版"4/4 币都更好"不成立**：把多巴胺门槛从 3× 手续费改成 1× 手续费（于是通道
  开始偶尔触发）后，**SOL 的符号翻转**（−0.977 → −0.754，从"更好"变成"更差"）。
  一次门槛调整就能翻转符号，说明那个 +0.03…+0.21pp 是**噪声量级**，不是 edge。
- `frozen` 与 `normal` 现在在 3/4 币上有差异（门槛变了，学习活性变了），方向不一致：
  SOL 上"不学习"好 +0.34pp，BTC 上"学习"好 +0.05pp，PONS 上"不学习"好 +0.03pp
  → **学习的效果是一个 ±0.3pp 的硬币**。

### 统计层（2026-09-29）：给冠军打分前，先扣掉"试了很多次"

15 个臂里挑最好的 = 15 只猴子抛硬币挑最幸运的那只。`flygate protocol` 现在自带
post-selection 统计（`flygate/eval/stats.py`，纯 numpy + 标准库，零新依赖）：

- **PSR / DSR**：冠军 Sharpe 在扣掉"N 个臂择优"之后的真实概率，DSR>0.95 才算存活；
- **PBO(CSCV)**：样本内冠军在样本外掉到中位数以下的频率（≈0.5 = 择优是噪声）；
- **MinTRL**：还需要多少根 K 线才可能显著；
- **HAC t**：臂间逐根配对差的自相关稳健 t 统计（持仓跨 K 线重叠，OLS 低估不确定性）。

首跑即给出诚实判定（3 天 × 4 臂）：全部冠军 SR 为负 → **DSR≈0.00–0.06，
minTRL=inf**——该窗口不存在可声明的 edge，与基线表的结论一致。
配套负向夹具 `tests/test_lookahead.py`：篡改未来 K 线后，崩盘前的权益曲线必须
逐位一致——前视偏差从此有测试钉住。

## 结构

```
flygate/
├── brain/flybrain.py     # 视网膜/板层/小叶/蘑菇体/DN 全网络（纯numpy LIF）
├── brain/circuits.py     # 环形吸引子朝向记忆 / LC4-LC6 逼近探测器（默认关）
├── data/gate_client.py   # Gate APIv4（公共行情+HMAC签名私有下单）
├── data/history.py       # K线分页抓取+CSV缓存（尊重1万根限制）
├── trader/broker.py      # 纸面/实盘 Broker（原子写；未确认成交不记账）
├── trader/risk.py        # 风控守卫+熔断（时间可注入=回测复用同一套；计数器持久化）
├── trader/engine.py      # 主循环：观测→多巴胺→决策→风控→下单→持久化
│                         # 单实例锁 runs/engine.lock；仪表盘指令排队给引擎线程执行
├── backtest.py           # 回放回测：七臂对照 + 暴露匹配扣费基准 + 同一套风控
├── eval/protocol.py      # 多种子 × 多臂 × 自举置信区间（`flygate protocol`）
├── radar/                # 新币雷达（≤6h 新币）：DexScreener 扫描 + GoPlus 审计 + 回测追踪
│                         # 不含钱包跟单信号（无链上钱包数据源，宁缺毋假）
├── storage.py            # 原子写 + 容错读（断电不毁状态）
├── server/               # 零依赖仪表盘（stdlib HTTP+SSE+单页前端，控制端点需 token）
└── tests/                # 76 项：大脑 / 协议 / 交易风控 / 期货安全 / 仪表盘鉴权
```

## 实盘前必读

1. 先纸面跑 ≥2 周，观察仪表盘的决策质量
2. 实盘首笔预算 ≤50 USDT，权当学费
3. Gate 费率：现货 0.2%（GT抵扣更低）；本策略频率低，费用影响可控
4. 新上架币（如 PONS）年化波动 >400%，min_quote 3 USDT，注意插针风险
